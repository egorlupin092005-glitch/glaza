# Проверка восстановленной программы

Дата: 26 октября 2026 года.

## Выполнено

- Установлено отдельное окружение Python 3.12.14 в `.venv`.
- `pip check`: конфликтов зависимостей нет. Точные установленные версии сохранены в `requirements-lock.txt`.
- 15 автоматических тестов: пределы углов, направление осей, зона покоя, плавность при разных частотах кадров, удержание при потере руки, отклонение некорректных настроек, подтверждения Arduino, частичные и неверные ответы, таймаут и перезапуск платы.
- Реальная модель MediaPipe загружена и инициализирована. Пустой кадр не обнаруживает руку; на официальном тестовом фото рука обнаружена.
- Полный цикл с реальной моделью, тестовыми кадрами и имитатором последовательного порта: обнаружение руки → команды двум осям и подтверждения → исчезновение руки → удержание → возврат к 90°/90° → корректное освобождение ресурсов. Передано 10 подтверждённых команд в проверочном запуске.
- Окно приложения создано, отрисовано и закрыто в тестовом режиме. Проверено, что до включения камеры движение и подключение платы недоступны. Снимок интерфейса: `interface.png`.
- Прошивка собрана для Arduino Uno (`arduino:avr:uno`, Arduino AVR core 1.8.8): 3936 байт программной памяти, 288 байт статической памяти. Предупреждения сборки относятся к неиспользуемым параметрам стандартного Arduino core `new.cpp`.
- Прошивка также успешно собрана для Arduino Nano (`arduino:avr:nano:cpu=atmega328`): 3936 байт программной памяти, 288 байт статической памяти.
- Установщик повторно запущен: успешно проверил зависимости и контрольную сумму модели.

## Что требует подключённого стенда

При проверке COM-портов подключённых устройств не обнаружено. Загрузка прошивки на физическую плату, направление вращения конкретных сервоприводов, питание, посадка рычагов и точность движения палочки не проверены.

Живая камера пользователя во время автоматических проверок не открывалась. Её доступность проверяется кнопкой «Включить камеру» в приложении.

Подтверждение команды Arduino означает принятие чисел прошивкой; обратной связи о фактическом угле SG90 нет.
